# Osteria Nova (Genova)

A responsive landing page for a fictional Italian restaurant, built twice with two
different approaches to compare and demonstrate both stacks side by side.

**React version** (genova-react): React 19 + TypeScript, Vite, Tailwind CSS v4, Framer
Motion for scroll animations, Lucide React icons. Features an interactive reservation
form with client-side validation, menu filtering by category tabs, and lazy-loaded
images for performance. GitHub: https://github.com/plamenzubev/genova-react

**WordPress version** (genova-wordpress): a custom PHP theme (WordPress 6.4+, PHP 8+)
built as a visual and functional twin of the React version, favoring classic
hand-written theme architecture over page builders. Features a server-side validated
AJAX reservation form with nonce protection and email delivery, content managed through
structured PHP rather than database-stored builder blocks, and vanilla JavaScript for
menu tabs and scroll animations. GitHub: https://github.com/plamenzubev/genova-wordpress

Both versions are fully responsive across mobile, tablet, and desktop.
