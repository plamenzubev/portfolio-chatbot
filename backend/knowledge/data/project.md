# Expense Tracker (React Native + Node)

A cross-platform mobile app for tracking personal expenses, built with React Native
on the frontend and a Node.js/Express REST API on the backend, backed by MongoDB.

Key features: category-based expense entry with a date picker, JWT auth with refresh
token rotation, and a production deployment with a live API.

This project demonstrates end-to-end ownership: mobile UI, REST API design, auth flows,
and shipping to production.
